the problem 02 / 25

OCI GenAI ships two APIs.

OpenAI-compatible for Llama, Grok and GPT-OSS. Native OCI SDK for Cohere. Switching between them means rewriting the client, not the prompt.

01 Two API surfaces Different SDKs, different auth, different response formats for the same service
02 Model lock-in Switching vendors means rewriting integration code, not just changing a model ID
03 Missing pieces RAG, agents, guardrails and vector search all need their own boilerplate
the solution 03 / 25

One constructor, two endpoints.

GenAIClient auto-routes between the OpenAI-compatible API and the native OCI SDK. Change a model ID and the client picks the surface, the auth and the response model.

quick start 08 / 25

Three lines to your first completion

python
from oci_genai_service import GenAIClient

client = GenAIClient(compartment_id="ocid1.compartment.oc1..xxx")
response = client.chat("Explain Oracle AI Vector Search in 3 sentences.")
print(response.text)

Defaults to meta.llama-4-maverick. Auth comes from ~/.oci/config; set OCI_COMPARTMENT_ID to skip the argument.

streaming 09 / 25

Tokens as they arrive

Pass stream=True and iterate. Each chunk arrives as soon as the model produces it, on both API surfaces.

python
from oci_genai_service import GenAIClient

client = GenAIClient(
    compartment_id="ocid1..."
)

for chunk in client.chat(
    "Write a haiku about databases.",
    stream=True
):
    print(chunk, end="", flush=True)

tools 11 / 25

Type hints become tool schemas

Decorate any function. The signature and docstring become an OpenAI-format schema. No JSON written by hand.

python
@tool
def get_weather(city: str) -> str:
    """Get current weather."""
    return f"72F in {city}"

@tool
def get_population(city: str) -> int:
    """Get population of a city."""
    return 1_000_000

agent = Agent(
    client=client,
    tools=[get_weather, get_population]
)
result = agent.run("Weather in Austin?")
rag 12 / 25

A document becomes an answer

python
from oci_genai_service import GenAIClient, RAGPipeline, OracleVectorStore

client = GenAIClient(compartment_id="ocid1...")
store  = OracleVectorStore(dsn="localhost:1521/FREEPDB1", user="genai", password="genai")

pipeline = RAGPipeline(client=client, vector_store=store)
pipeline.ingest("quarterly-report.pdf")

result = pipeline.query("What was revenue in Q4?")

agents 14 / 25

A tool-calling agent with memory

python
from oci_genai_service import Agent

agent = Agent(
    client=client,
    tools=[get_weather, get_population],
    max_steps=5
)

result = agent.run(
    "Weather and pop in Austin?"
)

print(f"Steps: {result.steps}")

cli 20 / 25

The same client, from a shell

The oci-genai command installs with the package: interactive chat, one-shot prompts, model browsing, embeddings and the full RAG loop.

bash
# interactive chat
$ oci-genai chat

# one-shot
$ oci-genai chat "Explain RAG"

# browse models
$ oci-genai models list --vendor meta

# embeddings
$ oci-genai embed "Oracle AI"

# rag ingest + query
$ oci-genai rag ingest ./docs/
$ oci-genai rag query "Main findings?"

configuration 22 / 25

Five environment variables

bash
# required
export OCI_COMPARTMENT_ID="ocid1.compartment.oc1..xxx"

# optional
export OCI_REGION="us-chicago-1"        # default region
export OCI_PROFILE="DEFAULT"            # oci config profile
export OCI_CONFIG_FILE="~/.oci/config"  # oci config path
export OCI_GENAI_API_KEY="your-api-key" # triggers api_key auth

Set OCI_COMPARTMENT_ID once and no GenAIClient constructor needs the argument again.
