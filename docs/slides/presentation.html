01
The Problem

OCI GenAI has two separate APIs.

OpenAI-compatible for Llama, Grok, and GPT-OSS. Native OCI SDK for Cohere. Switching between them means rewriting your client code every time you change models.

⚠

Two API surfaces

Different SDKs, different auth, different response formats for the same service

🔄

Model lock-in

Switching vendors means rewriting integration code, not just changing a model ID

🔧

Missing pieces

RAG, agents, guardrails, and vector search all require separate boilerplate

The Solution

One client.
Every model.

GenAIClient auto-routes between OpenAI-compatible and native OCI APIs. Change a model ID; the client handles the rest.

06
Quick Start

Three lines to your first completion

from oci_genai_service import GenAIClient client = GenAIClient(compartment_id="ocid1.compartment.oc1..xxx") response = client.chat("Explain Oracle AI Vector Search in 3 sentences.") print(response.text)

Defaults to Llama 4 Maverick. Uses ~/.oci/config for auth. Set OCI_COMPARTMENT_ID to skip the argument.

07
Streaming

Real-time token output

Pass stream=True and iterate. Each chunk arrives as soon as the model produces it.

from oci_genai_service import GenAIClient client = GenAIClient( compartment_id="ocid1..." ) for chunk in client.chat( "Write a haiku about databases.", stream=True ): print(chunk, end="", flush=True)

09
Function Calling

@tool makes it automatic

Decorate any function. Type hints and docstrings become OpenAI-format tool schemas. No manual JSON.

@tool def get_weather(city: str) -> str: """Get current weather.""" return f"72F in {city}" @tool def get_population(city: str) -> int: """Get population of a city.""" return 1_000_000 agent = Agent( client=client, tools=[get_weather, get_population] ) result = agent.run("Weather in Austin?")
10
RAG Pipeline

Document to answer in 4 lines

from oci_genai_service import GenAIClient, RAGPipeline, OracleVectorStore client = GenAIClient(compartment_id="ocid1...") store = OracleVectorStore(dsn="localhost:1521/FREEPDB1", user="genai", password="genai") pipeline = RAGPipeline(client=client, vector_store=store) pipeline.ingest("quarterly-report.pdf") result = pipeline.query("What was revenue in Q4?") print(result.text)

Agents

Tool-calling agent with memory

from oci_genai_service import Agent agent = Agent( client=client, tools=[get_weather, get_population], max_steps=5 ) result = agent.run( "Weather and pop in Austin?" ) print(result.text) print(f"Steps: {result.steps}")

Multi-turn sessions

Agent remembers context across conversation turns.

Configurable loops

Set max_steps to control how many tool calls the agent can make.

Automatic schemas

@tool decorator converts Python functions to OpenAI tool format.

18
CLI

Everything from the terminal

The oci-genai command installs automatically with pip. Interactive chat, one-shot prompts, model browsing, embeddings, and full RAG operations.

# Interactive chat $ oci-genai chat # One-shot $ oci-genai chat "Explain RAG" # Browse models $ oci-genai models list --vendor meta # Embeddings $ oci-genai embed "Oracle AI" # RAG ingest + query $ oci-genai rag ingest ./docs/ $ oci-genai rag query "Main findings?"

Configuration

Environment variables

# Required export OCI_COMPARTMENT_ID="ocid1.compartment.oc1..xxx" # Optional export OCI_REGION="us-chicago-1" # default region export OCI_PROFILE="DEFAULT" # OCI config profile export OCI_CONFIG_FILE="~/.oci/config" # OCI config path export OCI_GENAI_API_KEY="your-api-key" # triggers api_key auth

Set OCI_COMPARTMENT_ID once and skip passing it to every GenAIClient constructor.
